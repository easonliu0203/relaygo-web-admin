# 旅遊方案管理 - 快速參考

## 🎯 日常操作流程

### 新增旅遊方案
```
1. 點擊「新增方案」
2. 設定顯示順序和啟用狀態
3. 填寫繁體中文名稱和描述（必填）
4. 選填其他語言翻譯
5. 點擊「儲存」
```

### 編輯翻譯內容
```
1. 點擊方案的「編輯」按鈕
2. 切換到要編輯的語言標籤頁
3. 填寫或修改該語言的名稱和描述
4. 點擊「儲存」
```

### 查看翻譯狀態
```
列表頁面「翻譯完成度」欄位：
- ✅ 完成：8/8（所有語言都已翻譯）
- ⚠️ 75%：6/8（部分語言已翻譯）

編輯頁面語言標籤：
- ✅ 綠色勾號：該語言翻譯完成
- ⚠️ 黃色警告：該語言部分完成
- 無圖示：該語言尚未翻譯
```

## ⚡ 快捷鍵提示

- **Tab 鍵**：在表單欄位間快速切換
- **Enter 鍵**：在輸入框中按 Enter 不會提交表單
- **Esc 鍵**：關閉對話框

## 🔍 常見場景

### 場景 1：新增一個只有中文的方案
```
1. 新增方案
2. 只填寫「繁體中文」標籤頁的內容
3. 儲存
4. 翻譯完成度顯示：1/8 (12%)
```

### 場景 2：為現有方案補充英文翻譯
```
1. 編輯方案
2. 切換到「English」標籤頁
3. 填寫英文名稱和描述
4. 儲存
5. 翻譯完成度更新：2/8 (25%)
```

### 場景 3：批量檢查翻譯完成度
```
1. 查看列表頁的「翻譯完成度」欄位
2. 找出顯示 ⚠️ 的方案
3. 逐一編輯補充缺少的翻譯
```

## 💡 專業建議

### 翻譯品質
- ✅ 使用專業翻譯服務或母語人士審核
- ✅ 保持景點名稱的一致性
- ✅ 考慮文化差異調整描述
- ❌ 避免使用機器翻譯直接上線

### 內容長度
- 方案名稱：建議 10-30 字元
- 方案描述：建議 50-200 字元
- 避免過長影響 Mobile App 顯示

### 更新頻率
- 新方案：立即完成繁中、英文翻譯
- 其他語言：1 週內補充完成
- 定期審核：每季度檢查一次

## 🚨 注意事項

1. **繁體中文必填**：這是系統預設語言，必須填寫
2. **儲存前檢查**：確認沒有錯別字或格式問題
3. **測試驗證**：儲存後在 Mobile App 中測試顯示效果
4. **備份重要內容**：刪除前確認是否需要備份
